# 供应商鉴权与模型内置网络搜索

## 授权与模型来源

工具在清单的 `runtime.host_capabilities` 声明所需能力。工具宿主按本次调用签发短期 Bearer 授权，绑定工具、项目、会话、供应商和模型，进程结束时撤销。模型集的长期凭据留在后端。公共传输负责附加鉴权、禁止重定向、返回上游状态和 JSON。

- `session_model` 的 `source` 操作返回调用会话的供应商 ID、模型 ID、主会话协议，以及去掉用户信息、查询串和片段的生成地址 `generation_url`。`post` 可以使用主会话生成端点，也可以通过 `endpoint` 选择工具在 `runtime.session_model_endpoints` 中声明的同源端点和协议。宿主按绑定的供应商 ID 选择凭据，按目标协议附加鉴权，按原会话记录用量。一次工具调用内的续请求使用同一份模型配置和凭据。
- `provider_auth` 接受清单中的接口名称和 JSON 正文。接口名称对应的供应商与完整 HTTPS 地址位于工具的 `runtime.provider_endpoints`，且地址须与供应商已配置的生成或发现端点同源。可通过条目的 `auth_scheme` 指定端点鉴权方案。这个能力可以独立于调用会话的模型使用。

## 模型内置搜索

`network_search` 工具包维护 Responses、Anthropic 和 Gemini 三种搜索请求、提示词与响应解析。它获取调用会话的来源后，向同一个模型单独发送搜索问题，不携带主会话历史或工具清单。工具检查供应商返回的搜索行为，保留实际搜索词、来源、原始元数据与答案；Anthropic 暂停时由工具继续请求。每次上游实际返回的 Token 用量归属调用会话的「内置网络搜索」。

搜索路由集中在工具包的 `.tool/tool.json` 中。绝对地址按来源的协议、主机和有效端口匹配。一个域名承载多个服务时，可用 `search.source_path_prefix` 按路径段区分，较长的匹配优先。路由名称是包内标识，可以自行命名。目标端点由工具包声明，供应商显示名和项目文件夹名均不参与匹配。

例如调用方使用 `https://api.deepseek.com/chat/completions` 时，工具选定自己的 `https://api.deepseek.com/v1/responses`。Flash 的声明由 `search.model_tools` 指定为 `deepseek_web_search`，其他模型使用该路由的 `search.responses_tool`，缺省为 `web_search`。普通中转站的 `/租户/v1/chat/completions` 按包内相对地址 `../responses` 请求同站的 `/租户/v1/responses`。上游需要实际支持这个接口和搜索工具。对非标准地址，可以在同一份清单添加独立路由，例如：

```json
"tenant_search": {
  "protocol": "openai_responses",
  "url": "https://gateway.example/team/tools/responses",
  "search": { "source_path_prefix": "/team", "responses_tool": "web_search" }
}
```

## DeepSeek 独立搜索与网页读取

`deepseek_official_web_search` 自行构造官方 Search/Fetch 请求、检查错误、整理结果和保存长文本。使用自配 Key 时直接访问官方服务；留空时通过 `provider_auth` 为同一个请求附加模型集 DeepSeek 凭据。无需启动对话模型。

JSON Key 已配置但请求失败时不改用模型集。没有可用凭据时，工具返回配置位置并提示在模型集配置，或用 `action=configure` 写入本工具 JSON；传空字符串可清除 JSON Key。`config_info` 只读取配置，不发起网络请求或回显密钥。环境变量凭据、旧 Responses 配置和旧响应解析均已移除，不保留兼容分支。

`search` 支持 `query`、`count`（1～50，默认 10）、`need_content`、`ori_question`、`localization`；`fetch` 接收单个 `url`。只传调用者明确提供的定位信息。错误保留上游 HTTP 状态与实际使用的凭据来源；搜索空结果正常返回，Fetch 的 HTTP 成功不代表内容是有效资料，仍需 AI 阅读核实。没有模型用量的 Search/Fetch 不登记为对话模型 Token 消耗。

返回策略按字段及本次文本总量控制：默认单个 `snippet`、`summary`、`content` 超过 4,000 字符，或加入该字段会超过本次 12,000 字符文本预算时，将该字段完整保存到工作区 `web_searches/deepseek_<时间>_<随机标识>/`。阈值位于 JSON 的 `output.inline_field_chars`、`output.inline_text_budget`，统计不包含标题、网址等元数据。短字段保持原文直接返回；长字段由 `text_files` 给出相对路径、UTF-8 字节数、字符数和行数。存在落盘字段时另存索引 JSON，索引只引用长文本文件，不再复制正文；全为短内容或空搜索结果时不创建文件。保留上游原文，不裁剪、不伪造完整网页或修复上游排版。

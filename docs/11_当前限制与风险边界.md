# 当前限制与风险边界

> 本机服务身份和诊断日志部分于 2026-11-02 按当前实现复核；其余风险条目保留原有记录。功能变化后应同步更新对应边界，不把“本地应用”自动等同于“已经认证”。

## 本机服务身份

桌面模式分为对外访问网关和仅本机监听的 Python 后端。开启“允许外部访问”后，网关可监听所有网卡；Python 后端仍绑定 `127.0.0.1`。桌面壳的 `TIANCE_API_HOST` 当前控制网关监听地址，不应继续把它写成后端直连地址。

网关负责浏览器密码与登录会话，代理请求使用进程级内部凭证访问后端。后端除公开健康检查、静态界面及具有独立授权的能力桥端点外，拒绝缺少有效内部凭证的请求。网关会移除调用方提供的内部凭证头并填入真实凭证，不把浏览器 Cookie 转发给 Python 后端。

本机免密验证桌面壳的临时身份凭证及回环连接，不是仅凭 `127.0.0.1` 放行。浏览器登录受服务端空闲、绝对有效期和页面存活规则约束；撤销登录会关闭关联传输，不取消独立运行的 AI 任务。

使用要求：

- 外部设备应连接访问网关，不应暴露 Python 后端或原生 Shell API。
- “允许外部访问”和“设置访问密码”是独立配置。**未设置密码时，网关允许免密调用业务接口**；监听所有网卡不等于已经启用密码保护。外部访问前应在桌面客户端设置密码。
- HTTPS 也是独立配置。密码认证不等于传输加密；使用外部访问时应配置 HTTPS 或可信加密通道。监听所有网卡后实际可达范围由网卡、路由和防火墙共同决定。
- 不要在前端开发端口运行不可信页面或代理。
- 不要把当前后端端口提供给网页、浏览器扩展或不可信本机进程。
- 供应商配置、client tool、文件接口和模型调用应视为本机高权限能力。

## 供应商密钥

API Key 加密保存在本机，但能修改供应商 endpoint 并触发请求的调用方可能让后端把已保存密钥发送到新的上游。只应让可信使用者通过已授权界面使用供应商配置接口，并核对自定义 API 地址；当前访问密码没有多用户的分级账户权限。

错误和审计输出也应避免保存包含密钥的 URL 查询参数。排查日志或导出审计前先检查其中是否包含 Token、路径和请求正文。

网关普通逐请求日志默认关闭，警告与错误仍可能包含 URL 等诊断信息，不能据此认为日志已完成脱敏。`gateway.log` 及两份备份每份最多 8 MiB，运行时轮转；启动时旧超大日志只保留末尾 8 MiB。具体保留、排错覆盖及生效方式见 [开发、验证与发布](09_开发验证与发布.md#访问网关诊断日志2026-11-02)。这项保留策略只处理网关诊断文件，不清理会话和工具的正式记录。

## 工具执行

Python 工具在独立进程和私有依赖目录运行，但没有通用 OS 沙箱。工具权限是应用层控制；恶意 Python 包仍可能使用当前用户权限访问本机。

- 只安装可信市场和工具。
- 对工作区外文件、网络、凭据、环境修改和程序执行保持人工确认。
- 动态工具包装不会提高隔离级别。
- 依赖安装中途关闭程序可能留下不完整环境，需要重新安装或清理对应工具依赖目录。

## 在线市场与远端资源

远端索引、ZIP、Markdown 图片和重定向都属于不可信输入。当前实现仍需加强 DNS 重绑定、重定向前验证、解压总预算和同项目并发更新事务。不要连接不可信市场，也不要把私人项目中的 `.Tiance` 会话、路径和记忆当作可公开内容。

## 长会话

模型上下文由后端完整历史重建，没有“最近 100 条”限制；但前端打开主会话仍可能一次读取大量历史并受固定请求超时影响。极长会话可能出现加载慢或页面无法完成加载，不能用删除历史或缩短后端事实作为修复。

## 文档与大型文件

- DOCX 目录页码可能需要 Word 刷新。
- 复杂 LaTeX/HTML/Mermaid 可能降级为图片或警告。
- Office/PDF 预览对大型文件有较高内存峰值。
- 自动表格布局受字体和 GDI 可用性影响。
- 从不可信 Markdown 转换文档前，应检查本地图片路径和远端资源。

## 更新

正式更新包包含哈希和更新清单，但应用阶段仍应重新验证并采用安装目录级事务。更新前关闭正在运行的工具安装和文件写入；重要安装目录应保留可恢复备份。

## 非目标平台

当前正式发布主线为 Windows。macOS 和 Linux 没有经过同等打包、桌面壳、文件监听、字体测量和更新流程验证。

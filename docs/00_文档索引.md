## 文档性质

- 本目录描述当前真实实现和已确认的操作流程。
- 产品方向、讨论猜测和一次性实验结果不作为当前合同。
- 自动化测试通过不等于实现安全；安全和生命周期边界以实际执行路径为准。
- 示例中的版本号、路径和仓库名只是示例时，会明确标注。

## 权威来源

- 程序版本：`system/version.json`，并应与三个子项目清单保持一致。
- 前端命令和 Node 版本：`2_ReactWeb/package.json`、`pnpm-lock.yaml`。
- 后端依赖和 Python 版本：`1_PythonServer/pyproject.toml`。
- 桌面壳依赖：`3_PyWebView/pyproject.toml`。
- 测试包：`scripts/package-test.ps1`。
- 正式发布包：`scripts/package-release.ps1`。
- HTTP 合同：`1_PythonServer/app/api/routes/` 与 `app/schemas/`。
- 本地数据合同：`1_PythonServer/app/repositories/`、`app/infra/`。

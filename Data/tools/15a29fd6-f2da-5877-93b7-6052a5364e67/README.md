# 命令行执行

执行一条命令，等待直接启动的进程退出，返回退出码及当时已产生的标准输出、标准错误。具体调用参数和示例以 `.tool/input.schema.json`、`.tool/examples.json` 为准。

## 执行时限

AI 可以通过可选调用参数 `timeout_seconds` 设置本次命令的等待预算，省略时默认 30 秒，允许 1～300 的整数。超出范围或类型错误会明确报错，不会静默改成另一个值。该参数方便每次选择不同等待时间，无需在不同 Shell 的命令文本里编写超时逻辑。

内部时限到期后，只结束本次直接启动的命令进程，读取当时已有的输出，返回 `COMMAND_TIMEOUT` 和 `data.status=timeout`。不等待下级进程退出，不新增结束进程树的规则。操作系统尚未确认直接进程退出时，返回的退出码为 null，回收在后台等待，不阻塞工具结果。

`.tool/tool.json` 中的标准配置 `runtime.timeout_seconds` 是平台总执行时限，当前为 180 秒。后端读取并执行它；它不是每次调用参数，也不会因内部参数改变。内部预算设得更长时，平台仍可能先终止工具；确需更长运行时间，应由工具作者或用户调整清单配置。平台超时沿用现有终止处理，不保证工具还能生成自己的完成结果或返回尚未提交的日志。

## 输入输出与下级进程

输入和输出使用自动清理的临时文件，避免下级进程继承管道后，直接命令已经退出或超时但工具仍等待管道 EOF。正常结束或内部超时后按固定大小快照读取输出；读取位置独立，不移动下级进程仍在使用的写入位置。下级进程之后的输出不包含在已经返回的结果中。

`max_output_chars` 仍分别限制 stdout、stderr 返回的可见字符数，读取原始内容时也保持内存上限；超过部分明确标记截断。临时文件在执行期间会占用与实际输出相应的磁盘空间，不限制为返回字符数。文件资源在最后的继承句柄关闭后释放。

本工具仍面向会自行结束的短命令。独立后台任务应使用专门的后台启动方式并安排自己的日志去向。工具正常返回不会新增对子进程的清理；平台超时或用户取消时的处理仍遵循平台现有规则。

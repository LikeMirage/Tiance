# 天策主题制作说明

主题是主题集中的项目文件夹。`theme.json` 定义颜色、表面、边框、阴影、背景和编辑器集成，资源放在 `assets/`；`.Tiance` 是制作会话数据，不属于主题发布内容。

主题管理工具（调用名 `theme_designer`） 保留配色设计、查看、创建、复制、编辑、切换、恢复和删除功能。先读取参数 Schema 和相关使用说明，不能猜字段；`derive_palette` 可从主色等少量设计输入生成配色，详细字段使用 `edit` 修改。

用户已手动建立主题项目时，在该项目会话中调用 `initialize_current`。工具检查工作区是主题集已登记项目根目录、分类正确、真实路径在主题集下且没有目录链接。普通项目和其他集会拒绝，不能传任意目标路径。只补缺失的 `theme.json` 和本说明，已有文件不覆盖。缺失的主题使用工具自带浅色模板作为起点，不自动切换主题。不要另外创建一个临时主题来替代用户目标。

没有目标项目时用 `create` 创建完整主题，或 `clone` 以已有主题为起点；新主题有独立 ID。复制只处理主题工作文件，不复制源 `.Tiance` 会话数据。保持 ID 稳定，显示名称可以变。修改完成后通过 `switch` 按用户意愿应用。

背景图片路径相对主题包，使用已有背景导入参数让工具复制文件，不能把本机绝对路径写入发布主题。颜色尽量通过主题 token 控制，避免修改前端代码或在界面写死色值。注意文字/背景对比、悬浮和选中状态、深浅集成模式、透明背景叠加后的可读性。

删除使用平台项目删除流程，托管目录进入系统回收站，保留找回途径；当前生效主题或本次调用所在项目不能删除。先切换到别的主题再删旧主题，不自行 `rmtree` 用户文件夹。

验证：主题 Schema 可解析、可被列表发现；检查导航、项目看板、会话区、工具卡片、输入框、弹窗、编辑器及背景；正确报告尚未进行的视觉验证。发布只打包主题定义、资源和公开说明，不包含 `.Tiance`、私有会话、API Key 或测试输出。

源码相对安装目录：`1_PythonServer/app/schemas/themes/` 为格式合同；`app/services/themes/theme_catalog.py` 为读取和路径校验；`app/services/application/project_creation.py` 为界面新建流程；`app/services/application/project_scaffold.py` 为原地初始化；本工具 `program/main.py`、`palette.py`、`workspace_actions.py` 为设计、配色及项目生命周期操作。文档与程序不一致时核验实际 Schema，不猜行为。

# 能力与权限

## 登录后可以做什么

统一 GitHub 登录可被天策界面和 GitHub 工具共同使用：

- 创建、查看、修改、Fork 或删除仓库。
- 查看变化，提交、推送、拉取并维护分支和标签。
- 创建和处理 Pull Request、Issue、Release 与 Actions。
- 在在线市场中读取已授权的私人仓库。
- 把项目集、知识集、经验集、角色集、主题集、工具集或供应商集同步到私人仓库。

本地 Git 操作和读取公开仓库不应强制要求 GitHub 登录；只有访问私人资源或向 GitHub 写入时才需要授权。

## 实际权限由三层共同决定

| 层次 | 含义 |
| --- | --- |
| GitHub 账号权限 | 你本人是否能读取或修改目标仓库 |
| GitHub App 功能权限 | Tiance Desktop 是否获准执行提交、PR、Issue、Actions 等操作 |
| App 仓库范围 | 目标仓库是否在 `All repositories` 或已选择仓库范围内 |

三层都允许写入时，天策才能提交和同步。登录成功但仓库未授权，或者仓库已选中但 App 只有读取权限，相关操作仍会失败。

## 新手推荐设置

- 安装到个人账号。
- 选择 **All repositories**。
- 接受 App 请求的完整仓库权限。
- 在天策登录页确认权限齐全、仓库显示“读写”。

这种设置最适合刚开始使用 GitHub、账号中尚无敏感仓库的新用户。熟悉 GitHub 后，可以随时改为只授权指定仓库。

## 凭据与安全

优先使用本页的统一登录，不要把 GitHub 密码、Token 或设备验证码发给 AI。登录凭据保存在本机的专用密钥数据中，不写入项目、工具调用参数或普通日志。

退出天策登录只清除当前电脑保存的凭据，不会删除 GitHub 仓库，也不等于卸载 GitHub App。

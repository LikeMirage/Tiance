# Возможности и разрешения

## Что даёт единый вход

- Создание, просмотр, изменение, Fork и удаление репозиториев.
- Commit, push, pull, управление ветками и тегами.
- Работа с Pull Request, Issue, Release и Actions.
- Чтение разрешённых приватных репозиториев как онлайн-рынков.
- Синхронизация коллекций проектов, знаний, опыта, ролей, тем, инструментов и поставщиков.

Локальные операции Git и чтение публичных репозиториев не должны требовать входа. Авторизация нужна для приватных ресурсов и записи в GitHub.

## Доступ определяется тремя уровнями

| Уровень | Значение |
| --- | --- |
| Права учётной записи | Что сам пользователь может делать в репозитории |
| Разрешения GitHub App | Какие операции разрешены Tiance Desktop |
| Область репозиториев App | Включён ли репозиторий в установку App |

Для записи все три уровня должны разрешать изменения.

## Рекомендуемая настройка для новичка

- Установить App на личную учётную запись.
- Выбрать **All repositories**.
- Принять все запрошенные разрешения.
- Убедиться, что Tiance показывает полный набор возможностей и доступ чтения/записи.

Это подходит для новой учётной записи без конфиденциальных репозиториев. Позже область можно ограничить.

## Учётные данные и безопасность

Используйте единый вход. Не отправляйте AI пароль GitHub, токен или код устройства. Учётные данные хранятся в специальных локальных секретах, а не в проектах, параметрах инструментов или обычных журналах.

Выход из Tiance удаляет данные входа с этого компьютера, но не удаляет репозитории и не деинсталлирует GitHub App.

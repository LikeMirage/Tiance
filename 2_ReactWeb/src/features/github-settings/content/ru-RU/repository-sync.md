# Репозитории и синхронизация

## Три назначения репозитория

| Тип | Назначение | Где использовать |
| --- | --- | --- |
| Приватный онлайн-рынок | Установка отдельных проектов, инструментов или тем | Онлайн-рынок соответствующей коллекции |
| Репозиторий синхронизации | Резервное копирование и синхронизация всей коллекции | Панель «Облачная синхронизация» |
| Обычный Git-репозиторий | Commit, ветки и история обычного проекта | Инструменты Git и GitHub |

Они используют один вход GitHub, но имеют разные форматы и интерфейсы.

## Первый репозиторий синхронизации

1. Завершите вход и полную авторизацию.
2. Попросите AI создать приватный репозиторий или создайте пустой репозиторий на GitHub.
3. При `Only select repositories` добавьте новый репозиторий в область установки App.
4. Откройте онлайн-панель или «Облачную синхронизацию» нужной коллекции и привяжите репозиторий.
5. Перед первой отправкой просмотрите список изменений.

Рекомендуется один репозиторий на коллекцию.

## Безопасный порядок

Получение: `Выбрать репозиторий → Проверить получение → Просмотреть изменения → Подтвердить`

Отправка: `Выбрать репозиторий → Проверить отправку → Просмотреть изменения → Подтвердить`

Проверка ничего не изменяет. Если после неё локальная или удалённая сторона изменилась, создайте новую проверку.

Для целой коллекции используйте облачную синхронизацию, для обычного текущего проекта — Git-инструменты, а для установки отдельных элементов — источник приватного рынка.

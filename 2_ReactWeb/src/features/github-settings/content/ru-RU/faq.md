# Частые вопросы

## Вход выполнен, но репозиториев нет

Убедитесь, что Tiance Desktop установлен на владельца репозитория. В `Installed GitHub Apps → Tiance Desktop → Configure` выберите `All repositories` или добавьте репозиторий в `Only select repositories`, сохраните и обновите Tiance.

## Почему репозиторий только для чтения?

Один из трёх уровней — права учётной записи, разрешения App или область репозиториев — не допускает запись. Проверьте права read/write и подтвердите обновлённые разрешения App.

## GitHub показывает `Request`

Организация требует одобрения администратора. Дождитесь владельца организации или сначала установите App на личную учётную запись.

## Можно войти без репозиториев?

Да. Выберите `All repositories`, войдите, а затем попросите AI создать первый репозиторий.

## Почему новый репозиторий не появился?

При `All repositories` обновите страницу Tiance. При `Only select repositories` сначала добавьте его в настройках установки App.

## Выход равен удалению App?

Нет. Выход удаляет только локальные данные входа. Для отзыва доступа приостановите или удалите Tiance Desktop в Installed GitHub Apps.

## Нужно отправлять AI пароль или токен?

Нет. Используйте единый вход и не помещайте секреты в диалоги, проекты или публичные репозитории.

## Вход не завершается

Подтвердите авторизацию в браузере и проверьте доступ к `github.com` и `api.github.com`. Если код истёк из-за разрыва сети, отмените вход и начните заново после восстановления соединения.

## Не работает собственное GitHub App

Проверьте Device Flow, Client ID, установку App, права репозитория и принятие обновлённых разрешений. Client ID — это не App ID и не Client Secret.

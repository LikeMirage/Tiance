## 数字菜单

导航按层级推进：**集 → 分类 → 项目 → 会话列表 → 会话**。只开放一个集时自动省略选集层，任意集都适用。

- 内容列表排在前面，新建、切换等功能项排在后面并标注「【操作】」。菜单不显示内容数量，会话列表上方保留项目和当前会话名称。发送屏幕上的数字选择对应项。发送 `0` 返回上一级。
- 在会话中，单独发送 `5` 查看前5轮对话，`00` 暂停当前任务，`0` 返回，`menu` 选择集；其他普通数字和文字发给 AI。`05`、`000`、`金额为0` 等仍是普通文字。菜单模式中的 `5` 仍选择第5项，`00` 不暂停任务；输入新名称时可用 `5` 或 `00` 作为名称。
- 返回菜单不会暂停已经运行的任务。异步结果仍标注原会话，不会改动你当前所在菜单。
- 列表内容变化后，用当前最新一张菜单的编号。旧消息中的编号不会成为另一套可操作菜单。

## 快捷指令

| 指令 | 操作 |
| --- | --- |
| `menu` | 返回访问范围内的集；只有一个时直接进入 |
| `/sessions` | 当前项目的会话列表 |
| `/new`、`/new 名称` | 主会话列表中创建并进入新会话，名称可选；分类或项目列表中创建对应内容；子会话列表不支持 |
| `/actions` | 打开当前会话的操作菜单 |
| `/model` | 选择供应商和模型 |
| `5`、`/5`、`/history` | 查看当前会话前5轮对话，保持在会话中；不带斜杠的 `5` 只在会话中作为此指令 |
| `/groups` | 当前会话的下级会话分类 |
| `/files`、`/clear` | 查看、清除待发送文件引用 |
| `00`、`/stop` | 暂停当前会话，等待任务保存，不退出会话；`00` 仅在会话中生效 |
| `/status` | 查看会话状态 |
| `/map` | 当前集的关系图 |

`/new` 在会话内部不执行，请先发送 `0` 回到主会话列表。选择「新建主会话」后直接进入新会话，下一条文字发给 AI，无需先起名。会话中发送 `/actions` 可打开模型、历史和暂停等操作；菜单里的「返回当前会话」会恢复聊天。创建项目或分类、输入新名称时发送 `0` 取消。

分类列表提供「新建分类」「关系图」；具体分类内只提供「新建项目」。返回保留原列表和分页，单集入口返回时不会出现多余的选集层。关系图的刷新选项随生成提示一起显示，稍后到达的图片不会改动当前菜单编号。

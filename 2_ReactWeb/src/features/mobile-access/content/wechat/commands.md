## 数字菜单

导航按层级推进：**集 → 分类 → 项目 → 会话列表 → 会话**。只开放一个集时自动省略选集层，任意集都适用。

- 内容列表排在前面，新建、切换等功能项排在后面并标注「【操作】」。菜单不显示内容数量，会话列表上方保留项目和当前会话名称。发送屏幕上的数字选择对应项。发送 `0` 返回上一级。
- 在会话中，普通数字也是发给 AI 的文字；只有单独的 `0` 用于返回。`000`、`金额为0` 等仍是普通文字。
- 返回菜单不会暂停已经运行的任务。异步结果仍标注原会话，不会改动你当前所在菜单。
- 列表内容变化后，用当前最新一张菜单的编号。旧消息中的编号不会成为另一套可操作菜单。

## 快捷指令

| 指令 | 操作 |
| --- | --- |
| `/menu` | 返回访问范围内的集；只有一个时直接进入 |
| `/sessions` | 当前项目的会话列表 |
| `/new 名称` | 分类列表中创建分类；项目列表中创建项目；会话列表中创建会话 |
| `/model` | 选择供应商和模型 |
| `/5`、`/history` | 查看当前会话前5轮对话，保持在会话中；普通数字 `5` 仍作为消息发给 AI |
| `/groups` | 当前会话的下级会话分类 |
| `/files`、`/clear` | 查看、清除待发送文件引用 |
| `/stop` | 暂停当前会话 |
| `/status` | 查看会话状态 |
| `/map` | 当前集的关系图 |

`/new` 在会话内部不执行，请先发送 `0` 回到列表。不记指令也可以通过编号操作；会话列表中的「当前会话操作」提供模型、历史和暂停等入口。输入新名称时发送 `0` 取消。

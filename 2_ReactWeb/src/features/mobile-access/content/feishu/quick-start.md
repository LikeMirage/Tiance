## 扫码连接飞书

1. 打开天策「设定集 → 访问管理 → 飞书接入 → 连接配置」，点击 **扫码创建并连接**。
2. 用手机飞书扫描二维码，按页面提示创建机器人并确认授权。飞书可能询问是否通过 OpenClaw 扫码，这是此创建入口的平台提示。
3. 等待天策显示 **扫码连接成功**。天策会验证机器人接口可用性，并加密保存连接凭据，不需要复制 App ID 或 App Secret。二维码过期时重新获取；尚未显示成功时，不代表已经接入。
4. 在手机打开刚创建的机器人，私聊发送 `/start`。回到天策连接配置，在「用户授权」中打开自己的账号开关。
5. 在「访问范围」选择这个连接允许使用的集。默认只开启项目集；开启多个集时手机显示选集菜单。
6. 在手机选择分类、项目、会话，再发送任务文字。原有机器人连接保留，可在「当前连接」下拉框中切换管理。

如果天策显示 **21001：平台策略限制**，说明飞书已经拒绝该应用的接口访问。此时天策不会将其保存为可用连接。可联系飞书支持，或换账号重新扫码；不能仅凭手机号绑定状态判断账号是否支持。

## 发送文件

在选定会话后发送图片、录音、视频或文件，等机器人提示「已保存」，再发送处理要求。原文件保存在目标项目的 `远程收件/飞书/` 下，并作为该条要求的引用；带文字说明的文件消息会一并提交。识别录音、编辑 Office 等仍由会话中的普通工具完成。

让 AI 调用「对外消息发送」工具，可将电脑文件发回指定聊天，也可在任务途中发送文字汇报进度。接收 ID 可直接使用手机消息底部的来源标注。

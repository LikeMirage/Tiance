## 日常操作

每条回复标明所属项目与会话。浏览菜单时，普通文字和文件不会发送给上次会话；进入会话或点击「返回当前会话」后才恢复发送。也可明确回复一条已关联会话的机器人回复来切换目标，菜单消息不支持这种切换。

| 指令 | 操作 |
| --- | --- |
| `/start`、`/menu` | 打开集与项目菜单；只开放一个集时直接进入 |
| `/actions` | 打开会话操作，查看历史、切换模型或暂停 |
| `/projects` | 选择项目集、分类、项目 |
| `/sessions` | 选择会话 |
| `/new 名称` | 在项目的主会话列表创建并进入新会话；子会话列表不支持 |
| `/newcategory 名称` | 在当前集创建分类 |
| `/newproject 名称` | 在已选分类创建项目 |
| `/model` | 按供应商选择模型 |
| `/history` | 查看最近5轮用户消息和正式回复 |
| `/map` | 查看当前集的分类、项目、主会话关系图 |
| `/files` | 查看待发送文件引用 |
| `/clear` | 清除待发送引用，保留工作区文件 |
| `/stop` | 请求暂停当前会话 |
| `/status` | 查看当前目标和运行状态 |

会话正在运行时，新消息会明确提示未提交。可以先暂停，也可以切到其他会话；旧任务的结果仍标注原会话返回。

分类列表提供「新建分类」「关系图」；进入具体分类后只提供「新建项目」；进入项目后提供「新建主会话」。返回按钮回到原来的列表和分页；下级会话只列出有内容的分类。

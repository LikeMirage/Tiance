## 日常操作

每条回复标明所属项目与会话，并提供操作按钮。查看其他菜单不改变消息目标；只有选中会话或回复一条已关联会话的机器人消息，才切换目标。

| 指令 | 操作 |
| --- | --- |
| `/start` | 打开说明和导航按钮 |
| `/projects` | 选择项目集、分类、项目 |
| `/sessions` | 选择会话 |
| `/new 名称` | 在当前项目创建主会话 |
| `/newcategory 名称` | 在当前集创建分类 |
| `/newproject 名称` | 在已选分类创建项目 |
| `/model` | 按供应商选择模型 |
| `/history` | 查看最近5轮用户消息和正式回复 |
| `/map` | 查看当前集的分类、项目、主会话关系图 |
| `/files` | 查看待发送文件引用 |
| `/clear` | 清除待发送引用，保留工作区文件 |
| `/stop` | 请求暂停当前会话 |
| `/status` | 查看当前目标和运行状态 |

会话正在运行时，新消息会明确提示未提交。可以先暂停，也可以切到其他会话；旧任务的结果仍标注原会话返回。

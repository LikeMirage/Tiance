# Команды и файлы

Используйте личный чат бота или его меню команд.

| Команда | Действие |
| --- | --- |
| `/projects` | Выбор коллекции, категории и проекта |
| `/sessions` | Выбор основного диалога проекта |
| `/new Проверка` | Создать основной диалог из списка основных диалогов проекта; название необязательно |
| `/actions` | Открыть операции с диалогом |
| `/newcategory Работа` | Создать категорию в просматриваемой коллекции |
| `/newproject Заметки` | Создать и выбрать проект в текущей конкретной категории |
| `/map` | Схема текущей коллекции: категории → проекты → основные диалоги |
| `/model` | Выбрать поставщика, затем модель целевого диалога |
| `/history` | Показать последние пять пар сообщений пользователя и ИИ |
| `/status` | Текущие проект, диалог, модель и состояние |
| `/stop` | Приостановить выбранный диалог; дождитесь подтверждения |
| `/files` | Файлы, ожидающие отправки в диалог |
| `/clear` | Очистить ожидающие ссылки, сохранив сами файлы |
| `/start`, `/menu` | Открыть меню коллекций и проектов |
| `/help` | Инструкция |

## История и медиафайлы

Кнопка «查看前5轮对话» или `/history` возвращает последние пять пар сообщений по времени: текст пользователя, названия и пути ссылок, итоговые ответы ИИ, ошибки и состояние паузы. Незавершённый ответ помечается отдельно. Длинные тексты разбиваются без обрезки; рассуждения и результаты инструментов не отправляются. Запрос не вызывает модель и не меняет выбранный диалог. Кнопка в старом сообщении относится к диалогу, указанному в том сообщении.

Голосовые сообщения, аудиофайлы, обычные и круглые видеосообщения сохраняются как исходные файлы в `远程收件/Telegram/` целевого проекта. Без подписи они ожидают задания. Неподдерживаемое сообщение или завершившаяся неудачей загрузка не блокирует последующий текст. Если задание уже ждало неудавшуюся загрузку, отклоняется только это задание; можно повторно отправить файл либо продолжить другим текстом.

В списке категорий доступны создание категории и схема коллекции. Внутри категории доступно создание проекта. После нажатия отправьте показанную команду с названием. Для создания проекта выберите конкретную категорию, а не «Все проекты». Используются обычные правила настольного приложения; параметры API нового поставщика нужно заполнить на компьютере.

Схема показывает только просматриваемую коллекцию, включая пустые категории и проекты, до уровня основных диалогов. Большая схема делится на несколько исходных PNG, доступных для увеличения. Создание на телефоне обновляет списки компьютера, не меняя выбранный там диалог и черновик.

После выбора диалога используйте `/model`: поставщик → модель. Доступны модели чата включённых поставщиков. Подсказки и остальные настройки сохраняются; работающая задача использует прежнюю модель, новая — выбранную. Кнопка старого сообщения меняет модель именно указанного в нём диалога.

Кнопка входа в диалог под ответом бота или функция Telegram «Ответить» на сообщение, связанное с диалогом, переключает выбранный диалог. Сообщения меню не могут быть целью ответа. При просмотре меню обычный текст и файлы не отправляются в прежний диалог; сначала войдите в диалог или вернитесь в текущий.

Возврат сохраняет исходный список и страницу. Если разрешена одна коллекция, выбор коллекции пропускается в обоих направлениях. Показаны только непустые категории дочерних диалогов; создание основного диалога в них недоступно. Коллекция настроек диалогов не содержит.

Можно переключиться, пока задача работает. Её результат остаётся связан с исходным проектом и диалогом. Работающий диалог не принимает новое задание: остановите его или дождитесь завершения и отправьте текст повторно.

Документы, записи, изображения и видео сохраняются как файлы, а содержимое обрабатывают модель и инструменты. На телефон поступают итоговый ответ, ошибка или подтверждение паузы. Длинный ответ разбивается на сообщения. Путь к файлу в тексте не означает его отправку.

Для получения файла попросите ИИ вызвать включённый инструмент внешних сообщений, указав ID подключения, ID чата и локальный путь. ID источника добавлены в конец входящего мобильного сообщения. При необходимости включите инструмент в коллекции инструментов на компьютере. Получатель определяется переданным ID.

Этот же инструмент может отправлять обычный текст во время задачи: сообщать о ходе работы или задавать вопросы. Он не ожидает ответа. Если без ответа продолжать нельзя, ИИ должен задать вопрос, завершить текущий ход и продолжить после нового сообщения пользователя.

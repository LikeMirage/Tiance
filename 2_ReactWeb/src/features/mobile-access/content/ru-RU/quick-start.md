# Быстрый старт

## 1. Создайте бота

Откройте [@BotFather](https://t.me/BotFather), отправьте `/newbot`, укажите имя и свободное имя пользователя с окончанием `bot`. Скопируйте Bot Token и сохраните ссылку на бота. Для существующего бота используйте его токен. Вставляйте токен в настройки, а не в диалог с ИИ. [Официальная инструкция](https://core.telegram.org/bots/tutorial)

## 2. Подключите Tiance

1. Откройте **Настройки → Управление доступом → Telegram → Подключение**.
2. Вставьте **Bot Token**. В дополнительных настройках оставьте `https://api.telegram.org`.
3. Включите доступ Telegram. Дождитесь имени бота и состояния готовности. При ошибке исправьте причину и повторите.

При `ConnectTimeout` откройте настройки сети. Если прокси-программа включила системный прокси, выберите его. Иначе задайте пользовательский HTTP-прокси с адресом и портом из своей прокси-программы, сохраните и повторите подключение. Не используйте порт сервера Tiance вместо порта прокси.

## 3. Разрешите свой аккаунт

1. В личном чате своего бота нажмите **Начать** или отправьте `/start`.
2. На странице подключения дождитесь появления аккаунта в списке пользователей.
3. Проверьте имя, имя пользователя и ID. Включите переключатель доступа этой строки.
4. Дождитесь подтверждения на телефоне. Не разрешайте доступ незнакомым аккаунтам.

## 4. Выберите диалог

1. Отправьте `/projects`, выберите коллекцию, категорию и проект.
2. Выберите диалог или создайте новый командой `/new Проверка`.
3. Отправьте `/status`, проверьте проект, диалог и модель. Для смены отправьте `/model`, выберите поставщика и модель. Если список пуст, добавьте модель и включите поставщика на компьютере.
4. Отправьте «Ответь: получено». Итог придёт на телефон, полный процесс доступен на компьютере.

Следующие сообщения идут в выбранный диалог до нового переключения. Указывать его ID в каждом сообщении не нужно.

## 5. Передайте файлы

Выберите диалог, отправьте оригинал файла через вложения и дождитесь подтверждения сохранения. Затем отправьте остальные файлы, проверьте `/files` и напишите задание.

Файлы сохраняются в `远程收件/Telegram/<случайный каталог>/` внутри проекта. Подпись одиночного файла становится заданием после загрузки. Для альбома дождитесь сохранения и отправьте задание отдельно. Файл без выбранного диалога нужно отправить повторно после выбора.

Для первой проверки возьмите небольшой файл. Облачная загрузка ограничена 20 МБ; для больших файлов нужен отдельно развёрнутый Local Bot API. [Документация](https://core.telegram.org/bots/api#getfile)

Оставьте Tiance запущенным; можно свернуть в трей. Автоматический запуск после выхода пока не реализован.

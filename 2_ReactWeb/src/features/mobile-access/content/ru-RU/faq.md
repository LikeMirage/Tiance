# Частые вопросы

## Тайм-аут подключения

Проверьте настройки сети Tiance. Системный прокси должен быть включён в системе, одного запущенного прокси-приложения недостаточно. PAC-скрипты не выполняются; при необходимости укажите HTTP-адрес прокси вручную. Сохраните и повторите подключение.

## Ошибка 502, но бот работает

Запрос состояния страницы и приём Telegram — разные соединения. Ошибка опроса исчезает после успешного обновления. Ошибка включения или выдачи доступа остаётся до следующего действия. Проверьте журнал приёма и отправки, прежде чем создавать бота заново.

## Аккаунт не появился после /start

Проверьте, что подключение включено и сообщение отправлено именно указанному боту в личный чат. Страница подключения обновляется каждые пять секунд. Проверьте журнал и сеть. Пока доступ не разрешён, задания не принимаются.

## Как изменить Token

Отключите доступ, измените Token или Bot API и включите снова. Пустое поле использует сохранённый токен. Другой бот получает отдельное подключение, разрешения и задачи.

## Webhook или конфликт программ

Не используйте два получателя для одного бота. Если настроен Webhook, сначала убедитесь, что прежний сервис не нужен, и отключите его там. Tiance не удаляет Webhook автоматически. Остановите дублирующие программы опроса. [Приём обновлений](https://core.telegram.org/bots/api#getupdates)

## Файл не передан ИИ

Проверьте `/status` до отправки. Без выбранного диалога файл не сохраняется — выберите диалог и отправьте снова. Файл без подписи ждёт текстового задания; проверьте `/files`. Повторите неудавшуюся загрузку, если файл нужен; другое текстовое задание можно отправить без переключения диалога. `/clear` удаляет ссылки, но оставляет файлы.

## Большой файл не скачивается

Облачный `getFile` ограничен 20 МБ. Для больших файлов нужен доступный отдельно развёрнутый Local Bot API. Tiance его не устанавливает. [Официальное описание](https://core.telegram.org/bots/api#using-a-local-bot-api-server)

## Ответы на сообщения с компьютера тоже придут на телефон?

Автоматически возвращается только результат задачи, поступившей через мобильный вход. Новое сообщение с компьютера в том же диалоге не пересылается. Отправка файла инструментом выполняется отдельно по указанному ID.

## Можно ли закрыть Tiance? Сколько хранятся журналы?

Пока требуется запущенный Tiance с настольным подключением; можно свернуть в трей. Автоматическое пробуждение только запланировано.

Журнал ведётся с этой версии: последние 1 000 событий на подключение в локальной глобальной базе. Токены, тексты сообщений и содержимое файлов не записываются. Прошлые события не восстанавливаются. Полные диалоги и запросы модели остаются в данных проекта.

# 常见问题

## 提示 ConnectTimeout 或连接失败

先在「设定集 → 网络设置」检查代理。系统代理模式读取系统提供的代理地址；仅打开代理软件但没启用系统代理不一定生效。当前不执行 PAC 脚本；这种配置可改用代理软件提供的 HTTP 代理地址。保存后回到“连接配置”重试。

## 页面报 502，但手机仍然能聊天

设置页向天策查询状态、天策向 Telegram 收消息是两条请求链。前者短暂失败并不代表机器人已断开。页面恢复查询后会清除该查询错误；启用或授权操作失败则保留提示，直到再次操作。到“记录日志”检查是否还有接收、回传异常；不要仅凭一条 502 就重建机器人。

## 发送 /start 后看不到自己的账号

确认发给的是配置中显示的机器人，使用私聊而非群聊，并确认接入已启用。连接配置页每 5 秒刷新一次；等待刷新。仍没有记录时看日志和网络设置。新账号未获允许前不能提交任务。

## Token 修改不了，怎么换 Token

先关闭接入开关，修改 Token 或 Bot API，再启用。输入框留空表示继续使用已保存的 Token。更换为另一个机器人会使用独立连接，不会接管旧机器人的任务和授权。

## 提示已有 Webhook 或其他程序抢占连接

同一机器人不要同时接到两个收件程序。已有 Webhook 时，先确认原服务不再使用，再在原服务解除；天策不会擅自删除它。多个程序同时长轮询时，停止重复实例后再试。[Telegram 收件说明](https://core.telegram.org/bots/api#getupdates)

## 文件没交给 AI，或发到错误位置

发送前用 `/status` 核对会话。没有选会话的文件不会自动保存，选好后重发。没有附带说明的文件先进入待提交列表，用 `/files` 查看，再发处理要求。下载失败时，如仍要处理该文件请补发；无关文字可以直接继续发送，不需要切换会话。`/clear` 只清除引用，不删除工作文件。

## 大录音上传后下载失败

默认官方云端 `getFile` 下载上限为 20 MB。使用已部署且可访问的 Local Bot API 服务，才能采用它的大文件能力。天策不会自行安装该服务。[官方说明](https://core.telegram.org/bots/api#using-a-local-bot-api-server)

## 电脑继续聊天，手机还会收到回复吗

手机入口提交的任务，其最终结果会回到该任务的来源账号。后来在电脑端同一会话发的新消息不会自动回传。AI 显式调用文件发送工具另算，该工具按指定 ID 发文件。

## 关掉天策还能用吗？日志保存多久？

目前需要保持天策和桌面连接运行，最小化到托盘可以；退出后不能自动唤醒。自动唤醒方案已记入待实现文档。

“记录日志”从本次版本开始记录接入事件，每个连接保留最近 1,000 条，不补录过去的事件。日志保存在本机全局数据库，分页读取，不保存 Token、消息正文或文件内容；对话正文和模型请求仍在各项目的会话记录中查看。

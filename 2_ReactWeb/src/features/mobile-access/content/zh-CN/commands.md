# 指令与文件

这些指令在机器人私聊发送，也可以从 Telegram 的命令菜单选择。

| 指令 | 操作 |
| --- | --- |
| `/projects` | 依次选择集、分类和项目 |
| `/sessions` | 显示当前项目主会话，点击选中 |
| `/new 手机测试` | 在当前项目新建并选中名为“手机测试”的会话；标题可省略 |
| `/newcategory 办公` | 在当前浏览的集新建分类 |
| `/newproject 会议纪要` | 在当前浏览的具体分类中新建并选中项目 |
| `/map` | 返回当前集的“分类 → 项目 → 主会话”关系图 |
| `/model` | 先选择供应商，再选择当前会话使用的模型 |
| `/history` | 查看当前会话最近 5 轮用户消息与 AI 回复 |
| `/status` | 查看当前项目、会话、模型和运行状态 |
| `/stop` | 暂停当前选中的会话，收到暂停结果后再发新要求 |
| `/files` | 查看当前会话待提交的文件引用 |
| `/clear` | 清除待提交引用，已下载文件仍保留在工作区 |
| `/help`、`/start` | 打开使用说明和导航按钮 |

## 分类、项目和关系图

先用 `/projects` 选集和分类。分类列表提供“新建分类”“关系图”；项目列表还提供“新建项目”。点击新建按钮后，按回复中的格式发送带名称的指令。“全部项目”没有确定的目标分类，不能直接在其中新建项目。

关系图只包含当前浏览的集，不展开子会话。空分类、空项目也会显示；内容较多时分为多张 PNG 原图，打开后可放大查看。切换集后重新发送 `/map`，或点击该集的“关系图”。

各集复用电脑端创建规则。模型集创建的是待配置的供应商项目，仍需在电脑端配置 API 和模型。手机新建会话会通知电脑刷新列表，不改变电脑当前选择和草稿。

## 切换模型

选好会话后，点击“切换模型”或发送 `/model`，依次选择供应商和模型。列表与电脑端相同，仅显示已启用供应商的可用对话模型。只修改当前会话的模型，不替换角色提示词或其他设置；正在运行的任务保持原模型，下次发送时使用新模型。旧消息上的模型按钮始终操作该条消息标注的会话。

## 查看历史记录

点击“查看前5轮对话”或发送 `/history`，按从早到晚返回此会话最近 5 轮，包含用户文字、引用名称和路径、AI 正式回复，以及失败或暂停状态。不足 5 轮就返回现有记录；运行中的回复会标明尚未完成。长内容分条发送，不截断，不重新请求模型，不发送思考和工具执行过程。旧消息上的历史按钮查看该条消息标注的会话，不切换当前选择。

## 多个会话之间切换

点击回复下方的“回复此会话”，或者使用 Telegram 自带的“回复”功能回复那条机器人消息，都会切换到它对应的会话。通过“下级会话”可继续进入 AI 子会话、对话分支或四种功能会话，并逐层导航。设定集没有会话，其他集共用这些操作。

旧任务未完成也能切换会话。旧任务的结果仍标注原项目和会话，不会改发到后来选中的会话。目标正在运行时，新要求会被拒绝；先暂停或等待完成，再重发。

## 文件接收与回传

支持接收普通文件、音频文件、语音消息、图片、普通视频和圆形视频消息，均保存原件到目标项目的 `远程收件/Telegram/` 下。识别录音或解析文档由会话里的模型和工具执行。没有附带说明时先暂存文件引用，随后发送处理要求。

不支持的消息会提示本条未提交，不影响后续文字。文件下载失败也不会持续阻塞会话；若一条处理要求正在等待的文件失败，只拒绝这一条要求，避免漏掉文件执行。需要该文件时补发，也可以直接发送其他文字要求。

普通对话只回传最后正式回复、报错或暂停信息，不发送思考和工具过程。长回复会拆成多条，回复里提到文件路径不代表文件已经发送。

需要取回文件时，可以要求 AI 使用已启用的 **对外消息发送** 工具，明确指定机器人连接 ID、聊天 ID 和电脑上的文件路径；工具按指定目标发送，不自动猜测收件人。手机消息末尾的来源标注包含这些 ID。工具不可用时，先在电脑工具集中启用它。

任务途中也可用此工具单独发送文字，汇报进度或提出问题。工具只发送、不等待答复；需要用户回答才能继续时，AI 应提问后结束本轮，收到下一条消息再继续。

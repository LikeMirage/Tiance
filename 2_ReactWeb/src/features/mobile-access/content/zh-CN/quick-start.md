# 快速开始

## 1. 创建自己的机器人

1. 在 Telegram 打开官方 [@BotFather](https://t.me/BotFather)，发送 `/newbot`。
2. 按提示输入机器人显示名称，再输入以 `bot` 结尾且未被占用的用户名。
3. 复制 BotFather 返回的 Bot Token，保留机器人链接，后面需要打开它。

已有机器人的用户可直接使用现有 Token。Token 填在天策配置中，不要发给聊天中的 AI。创建步骤参见 [Telegram 官方教程](https://core.telegram.org/bots/tutorial)。

## 2. 在天策连接

1. 打开「设定集 → 远程访问 → Telegram 接入 → 连接配置」。
2. 将 Token 粘贴到 **Bot Token** 输入框；高级设置里的 Bot API 保持 `https://api.telegram.org`。
3. 打开 **启用 Telegram 接入**。等待显示机器人名称和就绪状态；失败时按错误提示修正后重试。
4. 在下方右侧的 **访问范围** 选择这个机器人可访问的集，开关自动保存。默认仅开放项目集；每个机器人连接单独设置。

若提示 `ConnectTimeout`，打开「设定集 → 网络设置」：代理软件开启了系统代理时选择“使用系统代理”；若系统没有提供可用代理地址，选择“自定义代理”，填写代理软件里实际显示的 HTTP 地址和端口并保存，再回来启用。不要把天策的本地服务端口填成代理端口，也不要照抄别人的端口。

## 3. 允许自己的账号访问

1. 在手机上打开第 1 步创建的机器人，点击 **开始** 或发送 `/start`。
2. 回到天策的“连接配置”，等“允许访问的用户”列表出现自己的账号。
3. 核对名称、用户名和 ID，打开这一行右侧的允许访问开关。
4. 手机收到“已允许访问天策”后，继续下一步。不要授权不认识的账号。

## 4. 选择项目和会话，发送第一条消息

1. 在机器人私聊发送 `/projects`。
2. 只开放一个集时会直接进入该集，开放两个及以上时先选择集，再选择分类、项目和已有会话；要创建新会话，发送 `/new 手机测试`。全部关闭时，手机端不能访问内容。
3. 发送 `/status`，核对回复里的项目、会话和模型。需要更换时发送 `/model`，依次选供应商、模型；列表为空时，先在电脑端模型集添加模型并启用供应商。
4. 发送“只回复收到”。等待正式回复；电脑端也可以打开同一会话查看完整过程。

后续直接发文字即可，直到你重新选择会话。不需要在每条消息前填写项目名或会话 ID。

关闭某个集后，它的旧按钮、旧会话选择和回复旧消息入口均不可继续访问；发送 `/projects` 重新选择。已经开始的任务仍在电脑端执行，关闭范围内的内容不会继续通过该机器人回传。

## 5. 发送文件让 AI 处理

1. 先按上一步选好会话，再从 Telegram 的附件入口发送原文件。
2. 等机器人回复“已保存”；多份文件可以逐个发完。
3. 发送 `/files` 核对待处理文件，然后另发“整理这几份文件，列出要点”之类的要求。

文件保存在目标项目的 `远程收件/Telegram/<随机目录>/`。单个文件带说明文字时，说明会在文件下载成功后直接作为任务提交；多图相册请等待收件完成后另发要求。未选择会话时会提示选择，本次文件不会自动落到其他项目，选择好后需要重发。

初次测试用小文件。官方云端下载有 20 MB 上限；更大文件需要另外部署 Local Bot API，不能只改一个地址就获得这项能力。[官方文件说明](https://core.telegram.org/bots/api#getfile)

使用期间保持天策运行，可以最小化到托盘；关闭软件后目前不能自动唤醒。
